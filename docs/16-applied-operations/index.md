# 应用运筹学与产业决策

运筹学把“资源有限、目标冲突、需求不确定”的现实问题转成决策变量、目标函数和约束。它与金融组合优化共享同一套建模语言，也可以落到物流、供应链、收益管理和制造排程。

## 应用地图

| 场景 | 决策变量 | 典型方法 | 可验证输出 |
|---|---|---|---|
| 供应链管理 | 订货量、库存和安全库存 | 随机规划、库存控制 | 缺货率、成本、服务水平 |
| 物流路径规划 | 路线、车辆和时间窗 | 最短路、VRP、整数规划 | 距离、车辆数、迟到率 |
| 收益管理 | 价格、容量和分配 | 动态规划、定价优化 | 收益、转化、容量利用 |
| 制造生产排程 | 工序、机器和人员 | 排程、整数规划 | 完工时间、瓶颈、利用率 |
| 资源分配 | 预算、人员和设备 | 线性/鲁棒优化 | 目标值、敏感度、不可行原因 |

## 统一建模模板

```text
定义需求与不确定性
→ 定义决策变量
→ 写出目标函数
→ 写出硬约束与软约束
→ 检查量纲、可行域和边界
→ 选择算法与求解器
→ 做敏感度和压力测试
→ 解释结果并监控漂移
```

## 与金融和 AI 的连接

- 组合优化中的预算、风险和换手约束可以迁移到供应链预算和生产资源约束。
- 强化学习可以近似动态定价、库存控制和路径决策，但必须比较动态规划或数学规划基准。
- 预测模型只提供需求或风险估计，最终决策仍由目标函数和约束定义。
