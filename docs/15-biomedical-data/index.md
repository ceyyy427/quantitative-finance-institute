# 生物医药数据科学

生物医药场景把数学、数据工程和领域知识放在同一个系统里：数据维度高、样本量有限、批次效应明显、测量误差复杂，且错误结论可能影响实验或临床决策。

## 学习主线

```text
概率统计与线性代数
→ 高维统计与正则化
→ 统计基因组学
→ 单细胞与多组学
→ 机器学习与因果推断
→ 可重复生物信息学工程
```

## 核心模块

- **统计基因组学：** 表达矩阵、变异、群体结构、多重检验和错误发现率。
- **高维数据挖掘：** PCA、稀疏回归、图模型、聚类和表示学习。
- **机器学习：** 分类、生存分析、风险预测、不平衡数据和校准。
- **Python 工程：** 数据校验、特征管道、实验追踪、可视化和测试。
- **因果与验证：** 混杂、批次效应、外部验证、隐私和数据许可。

## 必须明确的风险

1. 数据来源、样本选择和缺失机制；
2. 批次效应与实验平台差异；
3. 高维条件下的多重比较和过拟合；
4. 标签、患者信息和基因数据的隐私边界；
5. 研究结果与临床决策之间的验证距离。
