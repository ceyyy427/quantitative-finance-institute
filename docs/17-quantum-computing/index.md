# 量子计算

量子计算章节从线性代数开始，不把“量子优势”当成营销结论。读者先掌握态向量、幺正变换、测量概率和张量积，再讨论量子模拟、量子机器学习或组合优化。

## 学习主线

```text
复数向量空间 → 单量子比特 → 多比特张量积 → 量子门与测量
→ Grover/QAOA 直觉 → 噪声、误差与经典基准
```

## 必须建立的桥梁

- 量子态 $|\psi\rangle$ 是单位复向量；
- 量子门 $U$ 满足 $U^\dagger U=I$，因此保持范数；
- 测量概率是振幅模平方，而非振幅本身；
- 量子算法仍需要经典数据加载、测量和后处理；
- 任何“加速”都要与相同输入输出接口的经典算法比较。
