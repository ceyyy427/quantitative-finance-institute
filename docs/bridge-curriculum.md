# 桥梁型课程地图

这套知识库把数学当作底层操作系统，把 AI、金融、生物医药和产业决策看成不同的应用层。学习目标不是记住一组算法名称，而是能够用数学语言定义问题，再把模型可靠地实现、验证和优化。

## 总体能力链

```text
数学语言
→ 问题定义
→ 状态、数据与约束
→ 目标函数
→ 理论推导
→ 数值算法
→ 工程系统
→ 评估、优化与监控
→ 行业决策
```

## 数理背景学生的共同必修

| 必修模块 | 要解决的核心问题 | 数学底座 | 工程产出 |
|---|---|---|---|
| 机器学习优化方法 | 如何在约束下找到稳定解？ | 梯度、凸性、收敛、数值线性代数 | 优化器、梯度检查、收敛实验 |
| 深度学习数学 | 多层函数如何学习？ | 链式法则、矩阵微积分、概率 | NumPy 网络、自动微分对照 |
| 生成式 AI 与基础模型 | 如何学习和生成复杂分布？ | 最大似然、变分推断、随机过程 | 生成模型训练与评估 |
| 强化学习理论 | 如何在不确定环境中决策？ | MDP、Bellman 方程、动态规划 | value/policy iteration、策略评估 |
| 数据科学工程 | 如何让实验可复现、可部署？ | 抽样、误差、复杂度 | 数据管道、测试、版本和监控 |

必修课的统一验收不是“能调用库”，而是提交：一个手算例子、一个理论证明、一个完整实现、一个失败案例和一份误差分析。

## 选修模块

### 概率、随机分析与数值方法

从[概率基础](00-foundations/01-probability-basics.md)、[Brownian motion](01-stochastic-processes/01-brownian-motion.md)、[Itô 引理](02-stochastic-calculus/01-ito-lemma.md)进入随机微分方程、随机控制和扩散模型。

### 量子计算

以复数线性代数、张量积、测量和量子线路为基础，连接优化、采样和量子机器学习。量子章节必须区分理论加速、硬件噪声和实际可复现性。

### 金融科技

沿着[Black-Scholes](05-derivatives/01-black-scholes.md)、[Delta 对冲](05-derivatives/03-delta-hedging.md)、[风险管理](07-portfolio-risk/02-var-cvar.md)和[策略研究](12-strategies/01-research-workflow.md)学习定价、交易、组合和风险。

## 应用方向

| 应用方向 | 典型问题 | 连接的数学/工程能力 |
|---|---|---|
| 金融服务与投资管理 | 定价、对冲、组合、风险和资产配置 | 随机分析、优化、时间序列、回测 |
| 生物医药 | 基因表达、变异、单细胞、高维预测 | 概率统计、降维、正则化、因果推断 |
| 供应链与物流 | 库存、路径、配送和不确定需求 | 网络流、整数规划、随机优化 |
| 收益管理与定价 | 动态价格、容量和需求分配 | 预测、动态规划、约束优化 |
| 制造与资源分配 | 生产排程、设备和人员配置 | 排程、组合优化、鲁棒优化 |
| 数字经济 | 平台、匹配、激励和资源配置 | 博弈、机制设计、因果与优化 |

## 跨域学习方式

同一个数学对象要在至少两个领域中复用：

- **梯度：** 训练神经网络、校准定价模型、优化组合和拟合生物统计模型；
- **随机过程：** 期权价格、扩散生成模型、库存需求和生物信号；
- **凸优化：** CVaR 组合、正则化回归、资源分配和图像/基因组重建；
- **动态规划：** 强化学习、路径规划、库存控制和生产排程；
- **高维统计：** 因子投资、基因表达、异常检测和风险监控。

## 课程页面的统一标准

每门课都必须包含：

1. 数学对象、变量、假设和约束；
2. 至少一个完整证明或误差分析；
3. 从手算到完整代码的逐步实现；
4. 理论测试、数值测试和边界测试；
5. 失败案例、数据偏差和部署风险；
6. 到另一个应用域的迁移练习。
