# 机器学习与时间序列

金融机器学习首先是时间顺序问题。任何模型都必须说明信息在什么时候可用、标签如何形成、训练集和测试集如何分开，以及预测如何进入组合。

## 学习主线

```text
金融时间序列
→ 滞后特征与滚动统计量
→ 时间序列交叉验证
→ 防止标签泄露
→ 预测与概率校准
→ 组合构建与风险控制
```

## 必须回答的问题

- 特征在交易时刻是否已经可见？
- 标准化和缺失值填补是否只使用过去数据？
- 模型选择是否重复使用测试集？
- 预测误差如何转成仓位，仓位如何受到交易成本约束？
- 样本外结果是否经过不同市场阶段和压力情景检验？
