# 桥梁型数学知识系统扩展规范

## 核心定位

Quantitative Finance Institute 不只是一套金融课件，而是以数学为底层操作系统，把数学语言、数据科学工程、计算机科学、金融分析、生物学和数字经济连接起来的桥梁型知识库。

这里的“数学底层”包含：

```text
定义问题 → 建立假设 → 选择状态变量 → 构造目标函数
→ 推导模型 → 分析可识别性与稳定性 → 数值实现
→ 优化系统 → 验证与解释 → 部署和监控
```

AI 可以自动生成大量标准化代码、数据整理和基础分析，但知识库必须训练读者定义变量、识别约束、选择模型、证明算法和优化系统的能力。

## 课程层次

### 数理背景学生的共同必修

1. 机器学习优化方法：梯度、凸性、非凸优化、自动微分、数值稳定性。
2. 深度学习数学：反向传播、初始化、归一化、注意力、泛化与正则化。
3. 生成式 AI 与基础模型：最大似然、变分推断、扩散过程、Transformer 和规模化训练。
4. 强化学习理论：马尔可夫决策过程、Bellman 方程、策略梯度、近似动态规划和稳定性。
5. 数据科学工程：数据结构、实验设计、版本、测试、可复现和推理服务。

### 选修方向

- 概率与随机模型、随机分析、随机微分方程和数值方法。
- 量子计算与量子信息：线性代数、测量、量子线路和量子算法。
- 金融科技：量化交易、衍生品定价、风险管理和金融时间序列。
- 生物医药：统计基因组学、高维数据挖掘、因果推断和生物信息学。
- 运筹与决策：供应链、物流路径、收益管理、定价、生产排程和资源分配。

## 统一能力模型

每门课和每个知识页都要同时回答五个问题：

| 能力 | 必须回答的问题 | 证据 |
|---|---|---|
| 数学定义 | 变量、空间、约束和目标是什么？ | 符号表、假设、定理 |
| 理论推导 | 为什么这个公式或算法成立？ | 完整证明、反例、误差界 |
| 工程实现 | 如何写成可靠、可测试的代码？ | 完整源码、类型、测试 |
| 系统优化 | 如何提升稳定性、效率、成本和可扩展性？ | 复杂度、优化实验、基准 |
| 应用解释 | 结果如何影响金融、生物或运营决策？ | 案例、风险、失败分析 |

## 跨域接口

### AI ↔ 量化金融

随机过程和数值分析支持生成模型与风险模拟；优化和时间序列验证支持交易信号、组合构建和模型监控；金融约束反过来提供对鲁棒性、分布漂移和决策成本的真实测试。

### AI ↔ 生物医药

概率模型、线性代数和高维统计支持基因表达、变异检测和单细胞数据；机器学习工程支持特征管道、批次效应处理、可重复实验和临床验证边界。

### 运筹学 ↔ 金融与产业

同一套目标函数、约束和不确定性方法可以表达组合优化、供应链补货、物流路径、收益管理、动态定价、生产排程和资源分配。

## 页面与代码契约

- 页面元数据新增 `track`：`core`、`elective` 或 `application`。
- 课程页必须同时链接至少一个数学基础页、一个工程实现页和一个应用项目。
- AI 页面必须区分训练目标、优化算法、推理过程和评估指标。
- 生物医药页面必须说明数据来源、批次效应、隐私、可重复性和统计假设。
- 运筹页面必须明确决策变量、目标函数、约束、求解器和不可行处理。
- 每个应用项目至少包含一个可手算例子、一个完整 Python 实现、一个理论测试和一个失败情景。
